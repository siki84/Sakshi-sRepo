Sakshi-sRepo
============

Sakshi'sRepo

## Static website

A simple static webpage (`index.html` + `styles.css`) with no build step.

### Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

### Deploy on Vercel

1. Import this repository at https://vercel.com/new
2. Framework preset: **Other** (no build command, output directory = root)
3. Click **Deploy**

Or with the CLI: `npx vercel` from the repo root.
